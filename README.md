# Régi és új játékaim

Lidless játékai a böngészőben: klasszikus ötletek új köntösben és vadonatúj kalandok.

| Játék | Mappa |
|---|---|
| Ivy Nightshade (új, fejlesztés alatt) | `ivy-nightshade/` |
| Méh-mentés | később kerül ide |
| Almaszedés | később kerül ide |

Statikus oldal: Vercelen a repó gyökere a kimenet, build lépés nélkül.

Az Ivy Nightshade forrása a `src/ivy-nightshade/src/` mappában van; a kész, egyfájlos játékot a `python3 src/ivy-nightshade/build.py` állítja elő az `ivy-nightshade/index.html` helyére.
